# CP3 # 🦍 — Gorila x 100 Humanos

## 🎮 Tema
Uma batalha entre um gorila e 100 humanos. O gorila pode atacar, defender e recuperar energia, enquanto os humanos agem automaticamente.

---

## 📦 Descrição geral

Este projeto cria uma página interativa usando **HTML, CSS e JavaScript** que simula a batalha entre um gorila e 100 humanos. O foco está na lógica de programação, eventos, manipulação do DOM e armazenamento do estado com `localStorage`. A interface apresenta barras de status, animações simples, logs de batalha e atualizações dinâmicas.
